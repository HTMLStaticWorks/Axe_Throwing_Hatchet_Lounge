# Ironwood Hatchet Lounge - Multipurpose HTML Template

A premium, production-ready HTML template for Axe Throwing & Hatchet Lounge venues. Built with a rugged, dark lodge aesthetic, this template is perfect for entertainment venues, competitive sports bars, and event booking businesses.

## Features

- **13 Production-Ready Pages** (Home 1, Home 2, About, Services, Pricing, Blog, etc.)
- **Rugged Lodge Aesthetic** with custom wood-grain textures and ember particle effects.
- **Dark & Light Mode** support (Dark mode default).
- **RTL Support** for mirrored layouts.
- **Interactive Widgets:**
  - Tournament Calendar with status badges.
  - Occasion Selector for group bookings.
  - Animated Stats Counters.
  - Safety Tutorial Video Embed (Lazy-load).
- **SEO Optimized:** Semantic HTML, JSON-LD schema, and unique meta tags.
- **Fully Responsive:** Mobile-first approach using Bootstrap 5.

## Quick Start

1.  Clone or download the repository.
2.  Open `index.html` in your browser to view the template.
3.  Consult `documentation/index.html` for detailed customization steps.
